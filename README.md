# IPL-Dataset-Analysis

An exploratory data analysis (EDA) project on the Indian Premier League (IPL) dataset, focused on uncovering trends, patterns, and insights from IPL matches and player performances.

📌 Project Overview

The Indian Premier League is one of the most popular cricket leagues in the world, generating a large amount of match and player data every season.

In this project, I analyzed IPL match data to explore questions such as:

Which teams have performed consistently well?

Which players have had the biggest impact?

How have toss decisions affected match outcomes?

Which venues have hosted the most matches?

What are the scoring and winning trends across seasons?

What factors appear frequently in match victories?

The project uses Python, Pandas, Matplotlib, and Seaborn for data cleaning, analysis, and visualization.

🎯 Objectives

Clean and preprocess the IPL dataset.

Perform exploratory data analysis.

Identify important team and player trends.

Analyze toss and match outcomes.

Explore venue and season-wise patterns.

Create meaningful visualizations.

Extract actionable insights from historical IPL data.

🔍 Analysis Performed
1. Data Cleaning

Handled missing values.

Checked duplicate records.

Standardized column names and values.

Converted relevant columns into appropriate data types.

Prepared the dataset for analysis.

2. Season-wise Analysis

Analyzed the number of matches played across IPL seasons and explored how the tournament has evolved over time.

3. Team Performance

Compared teams based on:

Number of matches played

Matches won

Winning percentage

Season performance

Toss wins and match wins

4. Toss Analysis

Investigated the relationship between:

Toss winner and match winner

Toss decision and match outcome

Batting first vs. chasing

5. Player Analysis

Player of the Match awards

Match appearances

Performance across seasons

Most impactful players

6. Venue Analysis

Analyzed:

Matches played at different venues

Batting/chasing trends by venue
